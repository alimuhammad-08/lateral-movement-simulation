# Mobile Banking Security System Simulation

## Overview
A controlled network security simulation demonstrating penetration testing, network pivoting, traffic analysis, and defensive security controls.

## Environment
- Kali Linux (Attacker)
- Windows (Intermediate Target)
- Ubuntu Banking Server

## Tools Used
- Nmap
- Metasploit
- Hydra
- Nikto
- Wireshark
- Snort
- UFW

## Key Concepts
- Vulnerability Assessment
- EternalBlue (MS17-010)
- Network Pivoting
- Defense in Depth
- Information Assurance

## Disclaimer
This project was conducted in an isolated academic lab environment for educational and defensive security purposes only.
